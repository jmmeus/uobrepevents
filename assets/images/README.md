# Images Directory

This directory contains logo assets and images for the UoB Research Events site.

## Logo Files

Place your logo files here with the following naming convention:

- `logo-light.svg` (or `.png`) - Logo for light mode theme
- `logo-dark.svg` (or `.png`) - Logo for dark mode theme
- `favicon.svg` (or `.ico`/`.png`) - Favicon for browser tabs/bookmarks

## Format Recommendations

- **SVG** - Preferred for scalability and crisp rendering at any size
- **PNG** - Use high-resolution (2x or 3x) for retina displays if SVG not available
- **ICO** - Traditional format for favicons with best browser compatibility
